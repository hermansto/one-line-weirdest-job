## Entry

> Senior Vice President of Vibes

30 characters, under the 60-character limit.

## How it works

`main.ts` (Node, stdlib only) writes the title exactly — no trailing newline — to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`), then reads it back to verify it matches.
